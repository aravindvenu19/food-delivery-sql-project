# 🍔 Food Delivery SQL Project

## 📌 Overview

This project analyzes food delivery data using SQL and MySQL Workbench.

The project focuses on customers, restaurants, menu items, orders, order status, ratings, and revenue.

## 🛠️ Tools Used

- MySQL
- MySQL Workbench
- SQL
- GitHub

- restaurants
- menu_items
- orders_medium
- order_items(2)

## 🔍 Project Questions

This project answers questions related to:

- Customer order analysis
- Restaurant revenue
- Customer spending
- Restaurant ratings
- Cuisine performance
- Order status
- Menu item prices
- Delivered and cancelled orders

## 📊 Project Highlights

The SQL queries are used to:

- Find the highest revenue-generating restaurants
- Calculate customer spending
- Analyze restaurant ratings
- Find popular cuisines
- Count orders by customer and restaurant
- Filter orders based on their status
- Use joins, grouping, and subqueries for analysis
